# estol XMoment – Home-Assistant-Add-ons

[![Repository zu Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Festol-de%2Fxmoment-ha-addons)

## Add-ons

### [estol XMoment Connect](xmoment_connect/)

Bindet Ihr XMoment-Gerät mit einem Klick an Home Assistant an: Das Add-on findet das Gerät im Heimnetz
und überträgt den Zugang zum Mosquitto-Broker. Alle Casambi-Leuchten und Szenen des XMoment erscheinen
danach automatisch in Home Assistant – ohne Adressen oder Passwörter einzutippen.

## Installation

1. Mosquitto-Broker-Add-on installieren und starten (falls noch nicht vorhanden).
2. Auf den Knopf oben klicken (oder *Einstellungen → Add-ons → Add-on-Store → ⋮ → Repositories* und
   `https://github.com/estol-de/xmoment-ha-addons` eintragen).
3. **estol XMoment Connect** installieren und starten – fertig.
