# estol XMoment Connect

Bindet XMoment-Geräte mit einem Klick an Home Assistant an: Das Add-on findet das Gerät im Heimnetz und
überträgt den Mosquitto-Zugang. Casambi-Leuchten und Szenen erscheinen automatisch.
